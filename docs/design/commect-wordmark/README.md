# COMMECT 최종 타이포그래피

- 위: COMMECT / Inter 750.
- 아래: COMMODITY CONNECT / Inter 500.
- 아래 줄의 폭은 위 줄의 약 98%이며 두 줄을 중앙 정렬했다.
- 색상은 RGB (7, 35, 64), 정확한 #072340 단색이다.
- 투명 PNG: `commect-navy-transparent-4096.png` (4096×1152), `commect-navy-transparent-8192.png` (8192×2304).
- 흰색 반전 PNG: `commect-white-transparent-4096.png`, `commect-white-transparent-8192.png`. 남색과 같은 크기·알파 채널을 사용한다.
- 홈페이지에는 `images/brand/commect-wordmark-navy.png`와 `commect-wordmark-white.png`를 사용한다. 두 파일 모두 1024×240px 투명 PNG이며, 승인된 원본의 바깥 여백만 줄여 헤더·푸터 정렬에 맞췄다.
- `preview-white.png`는 확인용 흰 배경 미리보기다. 실제 사용 파일은 위의 투명 PNG다.
- 이미지 생성 모델 대신 프로젝트의 라이선스된 Inter 서체를 직접 렌더링하여 색상·크기·정렬을 맞췄다. 원본 로고를 확대하거나 보정한 파일이 아니다.
- 생성 기준은 `layout.json`, 재생성은 `render.py`, 서체 라이선스는 `FONT-LICENSE.txt`에 보관한다.
- 국문·영문 헤더와 푸터에 적용했다. 사진 위에서는 흰색, 고정 헤더·정책 페이지·모바일 펼침 메뉴·푸터에서는 남색을 사용한다.
