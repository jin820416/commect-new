비교 대상: [운영 중인 기존 사이트](https://www.commect.ai/)와 [현재 로컬 수정본](http://127.0.0.1:4173/).

**처음 지적한 5개 항목 중 수정본에서 4개는 해결되었고, 정책 페이지는 화면 복구를 마쳤으나 내용 확정이 남아 있다.** 운영 도메인에는 아직 배포하지 않았으므로, commect.ai에서는 기존 문제가 계속 확인된다. 이번 점검에서는 사이트 코드를 수정하거나 배포하지 않았다.

## 3. 디자인·사용성 비교

|---|---|

## 5. 이번 검증 범위와 결과

- 운영 사이트의 주요 5개 페이지와 정책 2개 경로, 폐기 대상 수탁 경로를 실제 브라우저에서 다시 열었다.
- 수정본의 한·영 14개 내용 페이지와 기존 정책 주소·수탁 경로를 확인했다.
- 한·영 14개 페이지 × 화면 폭 320·390·768·1,024·1,440·1,920px, **84개 조건**에서 문서 가로 넘침·주요 텍스트 내부 넘침·첫 화면의 로딩 완료 이미지 누락이 없었다. 모든 내용 페이지에 H1이 하나씩 있다.
- PC·모바일에서 서비스 항목을 유지한 영문 전환을 확인했다. 전환 후 대상 영역은 헤더 아래 약 24px의 여백을 두고 표시되었다.
- 모바일 메뉴 이동 후 닫힘과 회사소개 사진의 다음·이전 전환을 실제로 확인했다.
- 이번 점검에서 자동 테스트 **9개가 모두 통과**했다. 페이지·내부 링크·파일 경로·정책 이전 주소·폐기 경로 404·SVG 응답과 문의 성공·실패·필수 검증·중복 방지를 검사한다.
- 문의 자동 테스트는 실제 공통 스크립트에 모의 응답을 제공하는 검사다. 앞선 작업에서 사용자가 승인한 실제 테스트 문의 1건의 저장·완료 안내·해당 기록 삭제까지 확인한 기록이 있다. **이번 비교 점검에서는 새 문의를 제출하지 않았다.**

화면 폭 점검은 가로 배치와 첫 화면 이미지 확인을 위한 검사이며, 모든 환경에 대한 인증이나 정책 내용의 법적 적합성을 뜻하지 않는다.

## 6. 남은 사항

### 공개 전 확정할 사항

1. **정책 원문:** 문의 정보 보관기간·삭제 절차, 실제 처리위탁·보관 조건, 개인정보 담당자와 요청 처리 절차를 확정해야 한다. 국문·영문 약관도 검토용 초안에서 최종본으로 확정해야 한다. 화면이 복구되었다는 이유로 이 항목 전체를 완료로 표시하지 않는다.
2. **운영 도메인 반영:** 현재 수정본은 로컬에 있다. commect.ai에서의 문제 해결은 실제 공개와 공개 후 검증까지 진행해야 완료된다.

### 추가 마무리·선택적 개선

3. **영문 고유명사:** 영문 푸터의 주소·항목명·연락처는 영문으로 제공하지만 법인명 `㈜코멕트`와 대표자명 `김응진`은 한글로 남아 있다. 공식 영문 표기를 확인한 뒤 반영하면 영문판의 완성도가 올라간다. 영문 연결 자체의 오류는 아니다.
4. **서비스 사진:** 글로벌 네트워크의 화물선 사진과 시장 정보의 금융 차트 사진은 이전 이미지를 유지하고 있다. 문구는 정리되었지만, 사진만 보면 물류 수행이나 금융 트레이딩을 연상할 여지가 있다. 우선 금융 차트를 커피 시장·자료 검토 장면으로, 필요하면 화물선을 파트너 협력·산지 네트워크 이미지로 바꾸는 것이 새 방향에 더 잘 맞는다. 큰 레이아웃 변경은 필요하지 않다.
5. **이메일 수신 확인:** 링크 불일치는 해결되었다. `sales@commect.ai`의 실제 수신과 운영상 문의 처리 흐름은 별도 확인 대상이다.
