# COMMECT 웹사이트 변경 계획

작성일: 2026년 10월 22일

이 문서는 합의한 변경 계획의 기준본이다. 2026년 10월 22일 로컬 작업 파일에 적용했으며, 실제 검증 결과와 공개 전 남은 항목은 [구현·검증 기록](commect-verification.md)에 정리한다. 운영 사이트에는 아직 공개하지 않았다. 아래 치수는 구현과 한·영 화면 비교를 위한 초기 기준이다.

## 1. 목표와 작업 범위

현재의 사진 중심 구성, 로고, 색상 계열, 메뉴 구조, 서비스 카드, 이미지와 텍스트의 교차 배치를 유지한다. 문구의 방향과 디자인의 일관성을 정리해 차분하고 전문적인 글로벌 B2B 파트너의 인상을 만든다.

사업의 중심은 글로벌 트레이더와 한국 기업 사이의 연결, 요구사항 이해, 소통과 거래 협의 지원이다. 거래 시 글로벌 트레이더에게 중개료를 받는 구조이며, 홈페이지에서 수익 구조를 자세히 설명하지 않는다.

내용은 짧고 포괄적으로 유지한다. 상품 카탈로그, 상세 거래 조건, 장문의 실적 설명을 추가하는 것을 목표로 삼지 않는다. 컨설팅이라는 업종명도 전면에 강조하지 않는다. 문장에 사용되는 연결·이해·협력·지원이라는 동사로 역할을 드러낸다.

대형 글로벌 파트너의 역량은 폭넓은 선택과 시장 접근성으로 표현한다. 파트너의 실적이나 공급 능력을 코멕트 자체의 실적처럼 기술하지 않는다.

작업 범위:

- 국문 주요 5개 페이지의 문구와 시각적 위계 정리.
- 대응하는 영문 주요 5개 페이지 제작.
- 국문·영문 약관 및 개인정보처리방침 화면과 링크 정비. 본문은 운영에 맞는 원문을 기준으로 확정한다.
- PC·태블릿·모바일 공통 디자인 기준과 언어 전환 구현.
- 홈과 문의 페이지의 문의 양식 및 안내 문구 통일.
- 숨겨진 이전 물류 메뉴, 사용하지 않는 경로, 연락처 불일치 정리.

## 2. 현재 확인된 사항

- 홈페이지는 여전히 직접 트레이딩·생두 공급을 중심으로 설명한다.
- 현재 Pretendard와 Manrope 계열이 사용되어 새 서체 도입 없이 정리할 수 있다.
- 최대 폭, 좌우 여백, 세로 간격이 섹션마다 달라 사진·제목·카드의 정렬선이 일치하지 않는다.
- 홈에는 별도 제목 영역과 버튼 영역에 큰 세로 공간이 있어, 내용의 양에 비해 페이지가 길다.
- 문의 양식은 큰 카드 안의 실제 입력영역이 한쪽에 치우쳐 있다.
- 페이지별 스타일과 많은 인라인 글자 크기, 화면 폭별 덮어쓰기 규칙이 섞여 있다. 단순히 같은 숫자를 일괄 교체하면 서로 다른 역할의 요소가 함께 바뀔 수 있다.
- 모바일 언어 선택기를 숨기는 규칙이 있다. 영문 페이지 제작과 함께 제거·대체해야 한다.
- 약관·개인정보처리방침은 로컬 원본의 본문도 비어 있다.
- 표시 이메일과 실제 메일 링크의 수신 주소가 다르다.
- 문의 기능에 기존 데이터 저장 연결이 있다. 홈과 문의 페이지의 로딩·실패·성공 처리 및 버튼 문구를 함께 확인해야 한다. 이 계획 단계에서는 실제 문의를 제출하거나 데이터에 접근하지 않았다.

배경 이미지는 화면 전체 폭을 사용하되, 그 위 글자와 아래 본문은 같은 정렬선에 놓는다. 중앙 정렬은 섹션 도입에, 왼쪽 정렬은 설명·서비스 상세·양식에 사용한다.

사진과 글자 영역을 같은 고정 높이로 강제하지 않는다. 영문 문장이 길어져도 잘리지 않도록 콘텐츠에 따라 높이가 늘어날 수 있게 한다.

2026년 10월 22일 후속 검토에서 사용자가 가벼운 인상과 본문 비중을 지적하여 위 기준을 수정했다. 국문은 Pretendard를 유지하고 영문은 Inter로 바꾼다. 일반 본문 400, 강조 500–600, 주요 제목 700으로 위계를 분명히 한다. Inter는 공식 배포본을 로컬에서 제공하고 라이선스를 배포 파일에 함께 포함한다. 작은 글자나 옅은 색만으로 세련됨을 만들지 않는다.

보이는 크기와 문서 제목 구조를 별도로 정리한다. 각 페이지 대표 제목은 H1, 섹션은 H2, 카드·항목은 H3의 역할을 갖도록 한다. 현재의 H6 중심 구조를 그대로 복제하지 않는다.

기본 간격은 8px 단위로 관리한다. 기존의 빈 공간용 요소가 연속되어 생기는 중복 여백을 줄인다. 홈의 큰 첫 화면과 일반 설명 섹션은 서로 다른 역할로 관리한다.

홈 첫 화면은 PC에서 약 640–760px, 하위 페이지 사진 영역은 약 420–480px를 초기 범위로 삼는다. 모바일은 콘텐츠에 맞게 조정하며 높이를 고정해 글자를 자르지 않는다. 작은 노트북에서도 헤드라인·설명·문의 버튼의 관계를 확인할 수 있어야 한다.

### 색상·사진·컴포넌트

- 기존 짙은 남색 `#072340`을 주요 버튼과 중요한 강조에 유지한다.
- 기본 제목은 짙은 색, 본문은 `#4B5563` 수준의 읽기 쉬운 회색을 초기 기준으로 사용한다. 연한 회색은 테두리와 배경·장식에 한정한다.
- 기존 파란색은 섹션 라벨·선택 상태 등 제한된 역할에 사용한다.
- 주요 사진과 큰 카드의 모서리는 16px를 기본으로 정리한다. 버튼은 기존 캡슐형을 유지한다.
- 버튼과 입력창 높이는 48–52px, 설명 입력창은 약 160px를 초기 기준으로 한다.
- 이미지·카드에는 깊은 그림자보다 얇은 테두리와 절제된 그림자를 사용한다.
- 서비스 사진은 가능한 한 같은 비율로 맞추고, 기존 사진의 색온도·어두운 오버레이 강도를 통일한다.
- 서비스 역할 변경으로 의미가 어긋나는 금융·물류 사진만 필요한 범위에서 교체를 검토한다.
- 호버·포커스·선택·비활성·전송 중 상태를 공통 규칙으로 만든다. 키보드 포커스는 분명히 보이게 한다.
- 메인 문구·설명·버튼은 순차 등장하고, 섹션 제목·사진·서비스 카드·이용안내 카드는 스크롤로 처음 보일 때 한 번 등장한다. 18–24px 이동과 680–760ms 전환을 사용하고, 카드의 등장 시차는 최대 240ms로 제한한다.
- 기기의 움직임 줄이기 설정이 켜져 있으면 등장 효과를 생략하고, 재생 도중 설정을 켜면 즉시 중단한다. 기본 화면은 내용을 숨기지 않아 스크립트나 애니메이션 API가 없어도 읽을 수 있어야 한다.

| 구분 | 기준 |

| 중심 의미 | 글로벌 네트워크를 바탕으로 커피 비즈니스의 연결과 소통을 지원 |
| 주요 동사 | 이해합니다, 연결합니다, 함께 살펴봅니다, 협의합니다, 지원합니다 |
| 줄일 동사 | 직접 공급합니다, 직접 수입합니다, 모든 로트를 평가합니다, 보장합니다 |
| 줄일 수식어 | 최상의, 완벽한, 독보적인, 국내 최대 |
| 문장 길이 | 하나의 문장에 하나의 의미, 도입 설명은 1–2문장 |
| 정보의 양 | 현재 수준을 유지하거나 축약; 상세 상품·계약 자료를 새로 늘리지 않음 |
| 역할의 표현 | 컨설팅·중개라는 명칭보다 연결·협력·지원의 의미로 전달 |
| 국문 표기 | 파트너십, 네트워크로부터, 전 세계로 통일. 제목·메뉴·본문·양식·푸터까지 같은 기준 적용 |
| 한·영 관계 | 의미와 역할은 같게, 실제 줄바꿈과 문장 길이는 언어별 조정 |

국문·영문 대조표를 먼저 작성해, 한 언어에서 지원 역할로 쓴 문장이 다른 언어에서 직접 수행·보장으로 바뀌지 않도록 한다.

- PC 4열, 태블릿 2열, 작은 모바일 1열을 초기 배치로 삼는다.
- 영어 부제를 별도 중복 표기하기보다, 국문판에서는 간단한 보조 표기만 사용하고 영문판에서는 영문 제목 하나로 구성한다.

- 이메일 필수·전화번호 선택을 우선안으로 검토해 초기 문의의 부담을 줄인다.

## 7. 영문 페이지 계획

영문판은 국문판과 같은 브랜드·페이지·섹션 구조를 사용한다. 국내 기업뿐 아니라 글로벌 파트너가 읽는 상황을 고려해, 한국 시장과의 연결 역할이 자연스럽게 드러나게 작성한다.

영문 핵심 문장 예시:

> Connecting global coffee partners with businesses in Korea.

문구의 양은 국문과 비슷한 시각적 밀도로 조정한다. 직역으로 문장이 길어지면 영어 문장을 다시 다듬으며, 레이아웃에 맞추기 위해 글자를 작게 줄이지 않는다.

| 국문 페이지 | 영문 메뉴 | 영문 경로 계획 |
|---|---|---|
| 홈 | Home | `/en/` |
| 회사소개 | About | `/en/about` |
| 서비스 | Services | `/en/service` |
| 이용안내 | How We Work | `/en/process` |
| 문의하기 | Contact | `/en/contact` |
| 이용약관 | Terms of Use | `/en/policy` |
| 개인정보처리방침 | Privacy Policy | `/en/privacy` |

- 기존 국문 주소는 유지한다. 경로의 실제 출력 방식과 배포 설정은 구현 시 확인한다.
- EN 선택기에 남은 `#` 임시 링크를 실제 영문 페이지 주소로 교체하고, 국문 복귀 링크도 현재 페이지에 대응하도록 설정한다.
- 서비스 페이지에서 언어를 바꾸면 대응 언어의 서비스 페이지로 이동한다. 가능한 경우 현재 서비스 항목도 유지한다.
- 언어를 바꿀 때마다 홈으로 돌아가게 하지 않는다.
- 페이지 제목·설명·공유 미리보기·이미지 대체 설명·양식 오류·완료 안내·접근성 이름·푸터·정책 링크도 번역한다.
- 영어 페이지의 한국어 잔여 문구와 한국어 페이지의 오래된 영어 문구를 함께 확인한다.
- 언어별 문서 언어, 대표 주소, 대응 언어 연결 정보를 설정한다.
- 영어에서 더 길어지는 메뉴와 서비스명, 버튼, 성공·오류 안내에 충분한 폭을 확보한다.

## 8. 구현 방식

현재의 정적 HTML·CSS 구조를 기반으로 진행한다. 디자인 정리를 위해 새로운 프레임워크로 전체를 이전하는 작업은 기본 범위에 포함하지 않는다.

- 공통 글자 크기·간격·색상·폭·모서리 규칙을 한곳에서 관리한다.
- 역할별 스타일을 적용해 인라인 크기와 복잡한 화면 폭별 덮어쓰기 의존도를 줄인다. 원래 크기가 같다는 이유만으로 모든 요소를 일괄 교체하지 않는다.
- 헤더·푸터·메뉴·문의 동작을 국문·영문 및 페이지 간에 일관되게 유지할 구조를 먼저 마련한다.
- 언어별 정적 페이지를 제공하고, 번역 원고는 중앙에서 관리할 수 있게 한다. 화면이 뜬 뒤 본문 전체를 바꾸는 번역 방식은 기본안으로 사용하지 않는다.
- 기존 문의 저장 연결은 필요한 변경만 적용한다. 실제 구현 전에 해당 서비스의 현재 문서를 확인하고, 검증용 환경 또는 명확히 구분된 테스트 방식으로 접수 결과를 확인한다.
- 연결된 기능을 확인하기 전에 외부 라이브러리나 기존 스크립트를 대량 삭제하지 않는다.
- 초기 구현은 홈과 문의 페이지를 국문·영문으로 먼저 완성해 공통 규칙을 검증한 뒤 나머지 페이지에 확장한다.

## 10. 최종 검수 기준

### 내용과 인상

- 직접 재고를 보유·판매하거나 자체적으로 모든 통관·검수를 수행하는 회사처럼 단정하는 문장이 남지 않는다.
- 컨설팅이라는 단어를 과도하게 반복하지 않으면서 연결·지원 역할은 일관된다.
- 영문이 국문보다 과장되거나 보장 범위를 넓히지 않는다.
- 문장의 양은 현재보다 불필요하게 늘어나지 않는다.
- `파트너쉽`, `네트워크로 부터`, `전세계` 등 초기 확인 오표기와 이전 물류 서비스명이 현재 공개 원고에 남아 있지 않는다.

### 화면

- 한·영 주요 페이지를 390px·768px·1,440px 폭에서 비교하고, 360px·1,024px·1,920px에서 경계 문제를 추가 확인한다.
- 대표 제목·섹션 제목·카드 제목·본문의 크기 관계가 모든 페이지에서 같다.
- 로고·본문·카드·푸터의 정렬선과 좌우 여백이 맞는다.
- 큰 공백이 중복되거나 짧은 문장 아래 불필요한 고정 높이가 남지 않는다.
- 영어에서 카드·메뉴·버튼이 잘리거나 본문과 겹치지 않는다.
- 모바일에서 가로 스크롤, 작은 입력창, 잘못된 이미지·본문 순서가 없다.
- 본문 대비, 키보드 포커스, 확대 시 배치, 제목 구조를 확인한다.

### 동작

- PC·모바일의 메뉴, 현재 위치 표시, 언어 전환이 동작한다.
- 모든 언어의 내부 링크·서비스 바로가기·정책 링크가 실제 페이지로 연결된다.
- 국문·영문 홈과 문의 페이지의 필수 누락·전송 중·성공·실패 처리가 일치한다.
- 문의가 저장되었다는 사실이 확인된 경우에만 성공 상태를 표시한다.
- 연락처의 표시값과 실제 연결 대상이 일치한다.
- 새 페이지의 이미지·서체·스타일 경로가 하위 언어 경로에서도 정상 동작한다.
- 기존 국문 주요 주소와 직접 진입 경로가 유지된다.

### 초기 지적 사항의 완료 확인

- FIX-01: 약관·개인정보처리방침의 본문과 복귀 동선을 실제 화면에서 확인한다. 국문·영문과 기존 링크 변형도 확인한다.
- FIX-02: 표시 이메일과 메일 링크의 수신 주소를 위치별로 비교한다. 임의의 테스트 메일을 발송하지 않고도 확인 가능한 링크 대상 검증을 먼저 한다.
- FIX-03: 언어 전환용 `#` 임시 링크가 남지 않고, 대응 페이지 전환이 PC·모바일에서 실제 동작하는지 확인한다.
- FIX-04: 보세물류·파렛타이징·수탁 프로세스 등의 잔여 문구와 내부 링크를 확인하고, `/consignment` 직접 접근 결과도 검증한다.
- FIX-05: 국문 오표기 검색과 페이지별 육안 검토를 함께 진행하고, 한·영 명칭 대조표와 비교한다.

다섯 항목은 수정 여부와 검증 결과를 별도로 기록하며, 확인하지 않은 항목을 완료로 표시하지 않는다.

완료 결과는 기존 사이트의 인상을 유지하면서, 문구의 역할·화면의 정렬·글자의 위계·두 언어의 완성도가 일관된 사이트다.
